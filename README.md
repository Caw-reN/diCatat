# Catetin — Cozy Doodle Personal Finance App 🐾📓

Monorepo untuk aplikasi pencatat keuangan pribadi **Catetin** dengan tema UI **Hand-Drawn (Cozy Doodle & Pastel Notebook)** dan maskot **Si Kucing Oren Akuntan**.

## Struktur Monorepo
- `backend-laravel/` — REST API menggunakan Laravel, MySQL/MariaDB, Auth Sanctum + Google OAuth, dan Gemini Flash Vision API untuk Scan Struk Otomatis (AI OCR).
- `app-react/` — Aplikasi Web Mobile-First (React + Vite + Tailwind CSS + shadcn/ui + Rough.js + RoughNotation).
- `landing-nextjs/` — Landing Page Storytelling & Showcase Visual (Next.js App Router + Tailwind CSS + RoughNotation).
